ADSP-SC598 Evaluation Kits

The SC598 evaluation kits pair the EV-SC598-SOM (Rev. E) with either the EV-SOMCRR-EZKIT or the EV-SOMCRR-EZLITE carrier board. The processor has one 1.2 GHz Cortex-A55 core and two 1 GHz SHARC DSP cores. Bare-metal or FreeRTOS applications for the SHARC cores can be loaded by Linux through remoteproc.

Build

From buildroot/, select the carrier board and apply the debug image fragments:

# EZ-KIT
make BR2_EXTERNAL="${PWD}/.." adi_sc598_ezkit_defconfig

# or EZLITE
make BR2_EXTERNAL="${PWD}/.." adi_sc598_ezlite_defconfig

support/kconfig/merge_config.sh .config \
    ../configs/buildroot.fragment \
    ../configs/debug.fragment
make -j$(nproc)

The build produces emmc.img and flash.img, the kernel Image, a FIT image, device trees for both carrier boards, U-Boot loaders, and the ext4/UBI root filesystem images in output/images/.

Bootstrap SPI Flash with JTAG

JTAG is the documented and tested bootstrap path. The boot ROM cannot boot an SD card, and the GPIO expanders must be configured before the SD card can be used later in the boot flow.

  • Connect USB-C P1 on the SoM to the host.

  • Connect an ICE-1000/ICE-2000 to JTAG header P6 on the SoM, or connect the carrier board’s embedded debugger through micro USB P2.

  • Set SoM rotary switch S1 to 0.

Build the ADI OpenOCD fork, then start it with the A55 target configuration:

git clone https://github.com/analogdevicesinc/openocd
cd openocd
./bootstrap && ./configure && make -j$(nproc)
src/openocd -f adi-dbgagent.cfg -f adspsc59x_a55.cfg \
    --search tcl/ --search tcl/interface/ --search tcl/target/

In a second terminal, start a serial console at 115200 8N1 with flow control disabled. In buildroot/output/images/, load the U-Boot stages with gdb-multiarch -x u-boot.gdb (or gdb -x u-boot.gdb on RHEL/Fedora). Serve the images from the same directory, for example with python -m http.server. At the U-Boot prompt, program SPI flash:

=> sf probe
=> dhcp
=> wget ${fdt_addr_r} <host-ip-addr>:/flash.img
=> sf update ${fdt_addr_r} 0x0 ${filesize}

Set S1 to 1 and reset the board.

Hardware Notes

  • UART0 is routed through a FT232RQ to SoM USB-C P1. GPIO-controlled bus switches leave it disabled at boot.

  • The SoM eMMC and carrier SD-card slot share the SC598 SD controller; only one can be used at a time.

  • The EZ-KIT’s ADIN1200 Ethernet port and USB PHY are multiplexed and cannot be used together.

  • The EZLITE device tree enables ADIN1300 Gigabit Ethernet and the ADAU1372 audio codec by default. Its FT422 USB-QSPI interface is selected by jumper.

  • Use a Rev. E SoM. Rev. D uses a different GPIO expander and SPI NOR size; its UART routing differs and may suppress console output.
