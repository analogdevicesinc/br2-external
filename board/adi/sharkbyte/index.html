Standalone Applications:

Custom C/C++ applications can be created/compiled on a host with a GNU Compiler Collection (GCC) toolchain (with the appropriate flags), transferred over and run directly on the Sharkbyte.

GCC Compiler Target Triple #GCC_TRIPLE#
GCC version #GCC_VERSION#
Binutils version #BIN_VERSION#
