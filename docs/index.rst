ADI Buildroot External
======================

`Analog Devices Inc. <https://www.analog.com>`_
Buildroot external layer documentation.

This `br2-external <https://buildroot.org/downloads/manual/manual.html#outside-br-custom>`_
contains Buildroot configuration specific to ADI that cannot be mainlined.
Generic support for ADI evaluation boards is implemented in the
`ADI Buildroot tree <https://github.com/analogdevicesinc/buildroot>`_.
